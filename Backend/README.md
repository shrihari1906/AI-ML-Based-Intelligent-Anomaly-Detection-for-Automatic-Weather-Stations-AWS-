# AWS Anomaly Detection Backend

AI/ML-Based Intelligent Anomaly Detection System for Automatic Weather
Stations (AWS). Uses a trained **IsolationForest** model combined with
domain-specific physical checks (stuck sensor, dropout, spikes).

## Quick Start

### 1. Set up virtual environment

```bash
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS/Linux
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Train the ML model (first time only)

```bash
python train_model.py
```

This generates `anomaly_model.pkl` which `detector.py` loads at startup.

### 4. Start the server

```bash
uvicorn main:app --reload --port 8000
```

API: `http://127.0.0.1:8000` | Swagger docs: `http://127.0.0.1:8000/docs`

### 5. Run the sensor feed simulator

```bash
python test_feed.py                  # default 0.5s delay
python test_feed.py --delay 0.2      # faster
```

## API Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET`  | `/` | Health check |
| `POST` | `/data` | Submit a sensor reading |
| `GET`  | `/data` | Get all readings |
| `GET`  | `/alerts` | Get anomaly alerts (most recent first) |
| `GET`  | `/readings/{station_id}` | Last 50 readings for a station |
